# AgentVitals fix: Add name + autocomplete to inputs

**Failure class:** `fix.form.nameAndAutocomplete`  ·  **Severity:** critical  ·  **Occurrences:** 8

## Why agents get stuck
Agents fill forms by field name and autocomplete tokens; without them, checkout/signup stalls.

## Where (sampled)
- `input (no id/name)`

## Suggested change
```
<!-- before -->
<input type="text" placeholder="Email" />
<!-- after -->
<input type="email" name="email" autocomplete="email"
       id="email" aria-label="Email address" />
```
