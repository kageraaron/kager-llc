# CLAUDE.md: Watermark Remover

## User Experience
The primary goal is to create an intuitive and straightforward user experience. Users should be able to upload an image, select the watermark area with ease, and download the result with minimal friction. The interface should be clean, uncluttered, and responsive across devices.

## Aesthetic Considerations
- **Theme:** Clean, modern, and functional. A light theme is preferred, with subtle use of color to highlight interactive elements.
- **Typography:** Clear, readable sans-serif fonts.
- **Layout:** Responsive grid or flexbox layout that adapts well to different screen sizes. Emphasis on visual feedback during the image processing stages.
