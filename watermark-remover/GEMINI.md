# GEMINI.md: Watermark Remover

## Project Vision
To provide a fast, privacy-focused, client-side tool for removing watermarks from images. This utility aims to attract users seeking quick image editing solutions through organic search traffic.

## Technical Preferences
- **Frontend:** Vanilla JavaScript, HTML, CSS.
- **Processing:** Leverage browser APIs and potentially WebAssembly for image manipulation.
- **Deployment:** Static hosting on platforms like Vercel or Netlify for low cost and global reach.

## Monetization Strategy
- **Ad Banners:** Display tasteful banner ads on the main interface.
- **Interstitial Ads:** Show a brief interstitial ad before or after the watermark removal process, especially for larger files or more complex operations.
- **SEO Focus:** Optimize for search terms related to "watermark remover," "remove image watermark," etc.

## Core Features:
- Client-side image upload and processing.
- Intuitive interface for selecting watermark areas.
- Fast and efficient watermark removal.
- Option to download the processed image.
