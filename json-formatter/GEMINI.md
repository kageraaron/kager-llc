# GEMINI.md: JSON Formatter

## Project Vision
To provide an essential developer tool for JSON manipulation. This targets developers looking for a fast, reliable, ad-supported formatting tool that doesn't send their sensitive JSON payloads to an external server.

## Technical Preferences
- **Frontend:** Vanilla JavaScript, HTML, CSS.
- **Processing:** `JSON.parse` and `JSON.stringify`.

## Monetization Strategy
- **Ad Banners:** Display banner ads.
- **SEO Focus:** Optimize for "json formatter", "json validator", "beautify json", etc.
