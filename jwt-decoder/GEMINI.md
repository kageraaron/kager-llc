# GEMINI.md: JWT Decoder

## Project Vision
To provide developers with a highly secure tool for inspecting JWTs. Because pasting production tokens is risky, a verifiable client-side tool creates a strong unique selling proposition (USP).

## Technical Preferences
- **Frontend:** Vanilla JavaScript, HTML, CSS.
- **Processing:** Native JavaScript `atob` with Base64Url conversion.
- **Deployment:** Static hosting.

## Monetization Strategy
- **Ad Banners:** Display banner ads.
- **SEO Focus:** Optimize for "secure jwt decoder", "decode jwt locally", "no upload jwt parser".
