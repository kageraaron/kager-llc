# GEMINI.md: PDF Separator

## Project Vision
To provide a simple, client-side tool that splits a multi-page PDF document into individual PDF files, one for each page. This addresses a common user need for document management and sharing, aiming to attract organic search traffic.

## Technical Preferences
- **Frontend:** Vanilla JavaScript, HTML, CSS.
- **Processing:** Utilize a robust client-side PDF manipulation library such as `pdf-lib`.
- **Deployment:** Static hosting on platforms like Vercel or Netlify.

## Monetization Strategy
- **Ad Banners:** Display banner ads on the interface, particularly around the file selection and processing result areas.
- **Interstitial Ads:** Implement a brief interstitial ad upon completion of the PDF splitting process, especially for documents with many pages.
- **SEO Focus:** Optimize for search terms like "split PDF," "separate PDF pages," "PDF page splitter."

## Core Features:
- Ability to upload a multi-page PDF file.
- Option to specify page ranges or split all pages.
- Client-side splitting of the PDF.
- Download of individual PDF files for each page.
