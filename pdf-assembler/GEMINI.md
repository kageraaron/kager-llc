# GEMINI.md: PDF Assembler

## Project Vision
To provide a straightforward, client-side tool for combining multiple PDF documents into a single file. This utility targets users needing to merge documents for easier sharing or organization, aiming to capture organic search traffic.

## Technical Preferences
- **Frontend:** Vanilla JavaScript, HTML, CSS.
- **Processing:** Utilize a robust client-side PDF manipulation library such as `pdf-lib`.
- **Deployment:** Static hosting on platforms like Vercel or Netlify.

## Monetization Strategy
- **Ad Banners:** Display banner ads on the interface, particularly around the file selection and merge result areas.
- **Interstitial Ads:** Implement a brief interstitial ad upon completion of the PDF merging process, especially for larger numbers of files.
- **SEO Focus:** Optimize for search terms like "PDF merger," "combine PDFs online," "merge PDF files."

## Core Features:
- Ability to select multiple PDF files for merging.
- Clear display of selected files and their order.
- Option to reorder files before merging.
- Client-side merging of PDFs.
- Download of the merged PDF.
