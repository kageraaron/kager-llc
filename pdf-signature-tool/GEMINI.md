# GEMINI.md: PDF Signature Tool

## Project Vision
To develop a simple, client-side tool for adding basic signatures to PDF documents. This utility aims to assist users who need to quickly annotate PDFs without complex software, attracting organic traffic.

## Technical Preferences
- **Frontend:** Vanilla JavaScript, HTML, CSS.
- **Processing:** Utilize a client-side PDF manipulation library (e.g., `pdf-lib`) to add signature elements.
- **Deployment:** Static hosting on platforms like Vercel or Netlify.

## Monetization Strategy
- **Ad Banners:** Display banner ads on the interface, especially around the PDF upload and signature input areas.
- **Interstitial Ads:** Consider a brief interstitial ad after a signature has been applied and before the user can download the modified PDF.
- **SEO Focus:** Optimize for search terms like "add signature to PDF," "sign PDF online," "PDF signer."

## Core Features:
- Ability to upload a PDF document.
- Interface for drawing a signature or inputting text as a signature.
- Option to choose signature color and perhaps font for text signatures.
- Client-side application of the signature to the PDF.
- Download of the signed PDF.
