# GEMINI.md: Password Generator

## Project Vision
To provide a fast, secure, client-side tool for generating strong passwords. This utility aims to attract users seeking quick security solutions through organic search traffic.

## Technical Preferences
- **Frontend:** Vanilla JavaScript, HTML, CSS.
- **Processing:** Leverage browser Crypto APIs.
- **Deployment:** Static hosting.

## Monetization Strategy
- **Ad Banners:** Display banner ads.
- **SEO Focus:** Optimize for "secure password generator", "random password maker", etc.
