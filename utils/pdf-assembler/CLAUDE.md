# CLAUDE.md: PDF Assembler

## User Experience
The focus is on a simple, drag-and-drop or file-input-driven workflow. Users should easily be able to upload their PDF files, arrange them in the desired order, and initiate the merge process. Clear visual feedback on the progress and the final result is crucial.

## Aesthetic Considerations
- **Theme:** Clean, professional, and functional. A minimalist design with a neutral color palette (grays, blues) would be appropriate.
- **Typography:** Readable sans-serif fonts for clear text and labels.
- **Layout:** A responsive, multi-step or sectioned layout that guides the user through the process: file selection -> ordering -> merging -> download.
