# Unix Timestamp Converter

A simple, fast utility to convert Unix epochs to human-readable dates (and vice-versa).

## Features
- Live ticking epoch clock.
- Convert timestamps to Local, UTC, and ISO formats.
- Convert a specific date into an epoch.
- Auto-detects seconds vs milliseconds.
- Private: Entirely client-side using native JS APIs.

## Setup
No build steps required. Open `index.html` in a browser or deploy to a static host like Vercel.
