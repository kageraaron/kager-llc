# GEMINI.md: Unix Timestamp Converter

## Project Vision
To provide developers with a lightning-fast tool for converting Unix timestamps without server trips. It is a highly searched niche developer utility.

## Technical Preferences
- **Frontend:** Vanilla JavaScript, HTML, CSS.
- **Processing:** Native JavaScript `Date` API.
- **Deployment:** Static hosting.

## Monetization Strategy
- **Ad Banners:** Display banner ads.
- **SEO Focus:** Optimize for "epoch converter", "unix timestamp", "epoch to date".
