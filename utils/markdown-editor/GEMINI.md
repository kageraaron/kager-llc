# GEMINI.md: Markdown Editor

## Project Vision
To provide a fast, privacy-focused markdown editor for writers and developers. It serves as a quick utility that doesn't require logging in or saving files to a server.

## Technical Preferences
- **Frontend:** Vanilla JavaScript, HTML, CSS.
- **Processing:** `marked.js` library via CDN.
- **Deployment:** Static hosting.

## Monetization Strategy
- **Ad Banners:** Display banner ads.
- **SEO Focus:** Optimize for "markdown editor", "live markdown preview", "free markdown tool".
