# URL Parser & Query String Editor

A fast, client-side utility to deconstruct URLs and edit query parameters safely.

## Features
- Live parsing using the native browser `URL` object.
- Break down into Protocol, Hostname, Port, Path, and Hash.
- Automatically extracts query parameters into an editable table.
- Private: Entirely client-side.

## Setup
No build steps required. Open `index.html` in a browser or deploy to a static host like Vercel.
