# GEMINI.md: QR Code Generator

## Project Vision
To offer a fast, reliable, and user-friendly client-side tool for generating QR codes. This utility aims to capture organic search traffic from users needing to create QR codes for various purposes (URLs, text, contact info).

## Technical Preferences
- **Frontend:** Vanilla JavaScript, HTML, CSS.
- **Processing:** Utilize a well-established client-side JavaScript QR code generation library (e.g., `qrcode-generator` or similar).
- **Deployment:** Static hosting on platforms like Vercel or Netlify.

## Monetization Strategy
- **Ad Banners:** Display banner ads on the main interface, especially around the QR code display area.
- **Interstitial Ads:** Consider a brief interstitial ad upon successful QR code generation or before download, particularly for complex QR codes or if advanced options are used.
- **SEO Focus:** Optimize for search terms like "QR code generator," "create QR code," "URL to QR code."

## Core Features:
- Input fields for URL, text, contact information (vCard).
- Customizable QR code appearance (color, error correction level).
- Real-time preview of the generated QR code.
- Option to download the QR code as an image (PNG, SVG).
