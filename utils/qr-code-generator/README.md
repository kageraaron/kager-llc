# QR Code Generator

A simple, client-side tool to generate QR codes from text, URLs, or vCard information.

## Setup & Running

1.  **Clone the repository:**
    ```bash
    git clone <repository_url>
    cd qr-code-generator
    ```
2.  **Install dependencies (if any):**
    For this example, we assume a library like `qrcode-generator` might be used.
    ```bash
    npm install qrcode-generator
    ```
3.  **Open in browser:**
    You can run a simple local server or open `index.html` directly.
    ```bash
    # If using a simple HTTP server
    # python -m http.server 8000
    # Then open http://localhost:8000
    ```

## Usage

1.  Enter the text, URL, or vCard data you wish to encode.
2.  Customize options like color and error correction level if available.
3.  The QR code will generate in real-time.
4.  Download the QR code as an image file (e.g., PNG).
