# CLAUDE.md: HEX Code Color Picker

## User Experience
The interface should be intuitive and visually appealing, allowing users to easily upload an image and interact with it to select colors. Clear display of color values and simple copy-to-clipboard functionality are essential.

## Aesthetic Considerations
- **Theme:** Modern, clean, and visually focused on color. A minimalist design with a neutral background to make picked colors stand out.
- **Typography:** Clear, readable sans-serif fonts.
- **Layout:** A responsive layout that prioritizes the image display, the color picker interaction, and the clear presentation of color values. Color swatches should be prominent.
