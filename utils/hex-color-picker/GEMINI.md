# GEMINI.md: HEX Code Color Picker

## Project Vision
To create a simple, client-side tool that allows users to pick colors from uploaded images or directly from their screen (if browser permissions allow) and display their HEX, RGB, and HSL values. This utility aims to capture organic traffic from designers, developers, and artists.

## Technical Preferences
- **Frontend:** Vanilla JavaScript, HTML, CSS.
- **Processing:** Leverage the HTML5 Canvas API for image color sampling. Screen color picking might require more advanced browser APIs or user permissions.
- **Deployment:** Static hosting on platforms like Vercel or Netlify.

## Monetization Strategy
- **Ad Banners:** Display banner ads on the interface, particularly around the color display and image upload areas.
- **Interstitial Ads:** Consider a brief interstitial ad after a color has been picked and displayed, or when the user initiates a new action.
- **SEO Focus:** Optimize for search terms like "color picker from image," "get HEX code from photo," "online color sampler."

## Core Features:
- Image upload functionality.
- Ability to click on an image (or a representation of it on canvas) to pick a color.
- Display HEX, RGB, and HSL values of the picked color.
- Copy-to-clipboard functionality for color values.
- (Optional) Screen color picking capability.
