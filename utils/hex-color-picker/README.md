# HEX Code Color Picker

A client-side tool to pick colors from images and display their HEX, RGB, and HSL values.

## Setup & Running

1.  **Clone the repository:**
    ```bash
    git clone <repository_url>
    cd hex-color-picker
    ```
2.  **Open in browser:**
    Simply open the `index.html` file in your web browser. No build process or dependencies are required for this basic version.

## Usage

1.  Upload an image using the file input or drag-and-drop.
2.  The image will be displayed on a canvas.
3.  Click on any part of the image to pick the color at that point.
4.  The HEX, RGB, and HSL values of the selected color will be displayed.
5.  Click on the color values to copy them to your clipboard.
