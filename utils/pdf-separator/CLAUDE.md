# CLAUDE.md: PDF Separator

## User Experience
The user interface should be clean and straightforward, guiding the user through uploading their PDF, initiating the split, and then downloading the resulting pages. Clear instructions and visual feedback are key.

## Aesthetic Considerations
- **Theme:** Professional and functional, using a palette of blues, grays, and whites.
- **Typography:** Legible sans-serif fonts for all text elements.
- **Layout:** A responsive layout that clearly separates the upload area, the processing status/options, and the download links. A list view for downloaded pages might be useful.
