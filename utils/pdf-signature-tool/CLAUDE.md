# CLAUDE.md: PDF Signature Tool

## User Experience
The user interface should be intuitive, guiding the user through uploading a PDF, creating or inputting their signature, placing it on the document, and finally downloading the signed PDF. Simplicity is key, making it accessible for users who are not technically savvy.

## Aesthetic Considerations
- **Theme:** Clean, professional, and trustworthy. A palette of blues, grays, and whites would reinforce a sense of security and reliability.
- **Typography:** Clear, readable sans-serif fonts.
- **Layout:** A clear workflow, likely with distinct sections for PDF upload, signature input/drawing, signature placement on a preview, and final download. Responsiveness is important for mobile use.
