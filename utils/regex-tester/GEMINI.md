# GEMINI.md: Regex Tester

## Project Vision
To provide a fast, secure regex tester. Many online regex testers are heavy and send data to servers. Ours runs locally, guaranteeing privacy.

## Technical Preferences
- **Frontend:** Vanilla JavaScript, HTML, CSS.
- **Processing:** Native JavaScript `RegExp` engine.
- **Deployment:** Static hosting.

## Monetization Strategy
- **Ad Banners:** Display banner ads.
- **SEO Focus:** Optimize for "regex tester online", "javascript regex visualizer".
