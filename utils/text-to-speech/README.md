# Text to Speech Generator

A simple client-side utility to convert text into speech.

## Features
- Utilizes the browser's native `SpeechSynthesis` API.
- Pulls available voices directly from the user's OS/Browser.
- Adjustable pitch and reading speed.
- Private: Everything is synthesized locally; no audio or text is sent to a server.

## Setup
No build steps required. Open `index.html` in a browser or deploy to a static host like Vercel.
