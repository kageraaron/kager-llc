# Secure JWT Decoder

A fast, client-side utility to decode JSON Web Tokens without sending them to a server.

## Features
- Live decoding as you paste.
- Beautifully formatted JSON output for Header and Payload.
- Handles Base64Url encoding gracefully.
- Private: Entirely client-side using native JS APIs.

## Setup
No build steps required. Open `index.html` in a browser or deploy to a static host like Vercel.
