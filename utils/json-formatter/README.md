# JSON Formatter & Validator

A fast, client-side utility to validate, format, and minify JSON data.

## Features
- **Format:** Beautify minified or ugly JSON with 4-space indentation.
- **Minify:** Compress JSON into a single line.
- **Validate:** Instantly catch and display JSON syntax errors.
- **Private:** Processing is done entirely in the browser.

## Setup
No build steps required. Open `index.html` in a browser or deploy to a static host like Vercel.
