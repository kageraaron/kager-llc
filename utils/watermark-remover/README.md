# Watermark Remover

A simple, client-side tool to remove watermarks from images.

## Setup & Running

1.  **Clone the repository:**
    ```bash
    git clone <repository_url>
    cd watermark-remover
    ```
2.  **Open in browser:**
    Simply open the `index.html` file in your web browser. No build process or dependencies are required for this basic version.

## Usage

1.  Upload an image using the provided file input.
2.  Use the interface tools to select the watermark area.
3.  Click the "Remove Watermark" button.
4.  Download the processed image.
