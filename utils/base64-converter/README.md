# Base64 Encoder & Decoder

A fast, client-side utility to encode and decode strings to and from Base64 formats.

## Features
- **Encode:** Convert plain text to Base64 safely.
- **Decode:** Convert Base64 back to plain text.
- **Private:** Processing is done entirely in the browser using native `btoa` and `atob` APIs.

## Setup
No build steps required. Open `index.html` in a browser or deploy to a static host like Vercel.
