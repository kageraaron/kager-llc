# CLAUDE.md: QR Code Generator

## User Experience
The user experience should be streamlined and intuitive. Users should be able to input their data, customize basic options, and generate a QR code with minimal steps. A live preview is essential to provide immediate feedback. The interface should be clean and focused on the task.

## Aesthetic Considerations
- **Theme:** Clean, modern, and functional. A bright, light theme is appropriate, perhaps with accent colors for interactive elements or the QR code itself.
- **Typography:** Clear, legible sans-serif fonts.
- **Layout:** A simple, responsive layout that prioritizes the input fields and the QR code display. Visual cues should guide the user through the generation process.
