# GEMINI.md: URL Parser

## Project Vision
To provide developers and marketers with a safe, instant tool to inspect long URLs (especially those with tracking params) and edit them without relying on an external server.

## Technical Preferences
- **Frontend:** Vanilla JavaScript, HTML, CSS.
- **Processing:** Native JavaScript `URL` and `URLSearchParams` APIs.
- **Deployment:** Static hosting.

## Monetization Strategy
- **Ad Banners:** Display banner ads.
- **SEO Focus:** Optimize for "URL parser", "query string editor", "break down URL".
