# Regex Tester & Visualizer

A fast, client-side utility to test Regular Expressions and instantly visualize matches against text.

## Features
- Live syntax highlighting of matches.
- Native JavaScript `RegExp` execution.
- Configurable flags.
- Real-time match count.
- Private: Entirely client-side.

## Setup
No build steps required. Open `index.html` in a browser or deploy to a static host like Vercel.
